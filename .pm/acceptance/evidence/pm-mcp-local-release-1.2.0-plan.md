# pm-mcp 本地评价计划（基线 1.2.0）

基线：pm-mcp-local-release@1.2.0。本版只做一处同步：把 `QR-FS-TOOLS` 的 `MCP tools` 阈值与配套测试 `AT-FS-TOOLS` 的断言，从 `equal 48` 改为 `equal 58`。

原因是 1.1.0 冻结的工具数已被产品演进超过：M2 与 M4 新增编排能力后，直连探针实测工具数为 58。`equal` 断言对“新增工具”天然不可能满足，导致 `npm run gate` 在 acceptance 阶段恒定失败，任何自动编排轮次都无法收轮。

不变的部分：其余全部量化阈值、验收要求、风险与测试追踪、评价策略、冻结指针与证据摘要规则均原样保留。本版没有降低任何门槛来消除失败——除工具计数外的每一项仍与 1.1.0 相同。

执行顺序：

1. 基线批准后在当前工作区重新采集产品证据，绑定当次源码摘要。
2. 执行结构、安全、许可证与治理检查；有硬红旗不推进。
3. 完整执行 test、build、typecheck、coverage；门槛维持行 90%、分支 85%、函数 90%，保留全部失败/跳过/缺失结果。
4. 按冻结指针复算证据 SHA-256，生成不可覆盖的机器判定报告。
5. 报告与原批准基线一并入库，1.1.0 保持不变。

范围边界：Windows x64 本地第一方评价。批准仅用于解除门禁死锁，不构成远程发布授权、独立认证或托管 CI 证明。历史上已记录的 20 GiB 容量基准仍按其原始日期作为既有资格证据，不冒充本版新增压测。

回滚：1.1.0 基线与其评价证据保持原样未修改；`package.json` 的 `pm_mcp.acceptance_baseline.version` 指回 1.1.0 即回到旧状态。
