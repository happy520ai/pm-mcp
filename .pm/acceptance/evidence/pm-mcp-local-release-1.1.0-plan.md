# pm-mcp 0.3.0 本地评价计划

基线：pm-mcp-local-release@1.1.0。依据用户在 2026-09-08 的“直接开工”指令，执行上一轮明确提出的版本生效检查、任务分页、完成证据分级三项范围；保留全部 48 个 MCP 工具。

原已批准 1.0.0 基线保持不变。1.1.0 沿用其余量化门槛与验收策略，只同步产品版本、48 工具清单与已存在的最低 Node.js 版本 22.18。批准身份明确记录了由 Codex 按项目负责人授权执行，不构成独立认证或远程发布授权。

执行顺序：

1. 完成基线批准后，在隔离副本重新构建。
2. 执行结构、安全、许可证和架构检查；失败不推进成功状态。
3. 完整执行 test、build、typecheck、coverage；覆盖率门槛维持行90%、分支85%、函数90%，保留全部失败/跳过/缺失结果。
4. 核对测试前后源码摘要；执行新 MCP 参数、实际运行版本/项目根及安装包验证。
5. 采集当前测量，按基线冻结指针生成评价输入，复算证据摘要并生成不可覆盖报告。

范围边界：Windows x64 本地第一方评价；托管 CI、其他平台、生产环境和现有客户端重连分别报告。历史 20 GiB 容量记录只作为注明日期的既有资格证据，不冒充本次 0.3.0 的新压测。没有降低门槛来消除失败。

回滚：本轮开始前已备份源码、测试、脚本和安装元数据；配置升级保留旧文件备份，且只更改已确认项目启动项的 command/args。原工作区其他未提交改动不暂存、不重置。
