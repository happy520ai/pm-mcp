# pm-mcp 本地评价计划（基线 1.4.0）

基线：`pm-mcp-local-release@1.4.0`。本版为 0.8.0 发布同步：产品版本从 0.7.0 更新为 0.8.0，`mcp_tools` 保持 `equal 59`，其余全部量化阈值、验收要求、风险控制、测试追踪、评价策略与证据摘要规则不变。

发布内容：边界可靠性硬化（工作区歧义 fail-closed、核心账本完整性、轮次一次性结算与目标完成态、质量报告结构校验、幂等缓存回收、任务/会话写入回滚）与 UI/CI 增强。0.8.0 不新增工具，工具目录仍为 59。

执行顺序：

1. 基线批准后在当前工作区重新采集产品证据，绑定当次源码摘要。
2. 先运行 `npm run quality` 生成与当前源码绑定的质量报告，再执行结构、安全、许可证与治理检查；有硬红旗不推进。
3. 完整执行 test、build、typecheck、coverage；门槛维持 package.json 的 lines 95%、branches 85%、functions 93%，保留全部失败/跳过/缺失结果。
4. 按冻结指针复算证据 SHA-256，生成不可覆盖的机器判定报告。
5. 报告、发布 tarball 与基线一并入库；1.3.0 及其评价证据保持原样。

范围边界：Windows x64 本地第一方评价，Node.js ≥ 22.18。批准用于 0.8.0 发布前的本地质量基线同步，不构成独立认证；GitHub Release 与 npm 发布是后续独立操作。

回滚：`package.json` 的 `pm_mcp.acceptance_baseline.version` 指回 1.3.0 即回到旧基线；0.8.0 发布本身不可通过此回滚撤销。
